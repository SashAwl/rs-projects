"Hello! My name is Sasha. I am 35. I am from Nizhny Novgorod, Russia. I am an informatics teacher, but a few years ago, I realized that I want to be a developer. Now I am moving in this direction with confidence."

"For several years, I worked as a school teacher. But I always felt that I needed more technical knowledge.
I wanted to go beyond school books and understand how modern technologies work.
First, I decided to study programming. At university, I had a good base in TurboPascal. But I wanted to learn a modern and popular language – Python. I already knew some HTML and CSS, and together with Python, it led me to web development.
But I thought it was not logical to study backend without knowing frontend. So I started learning frontend.

My first course was on Coursera. Then I joined a sprint at Geegbrains and won a one-year frontend course. During the year, I studied HTML, CSS, JavaScript, Node.js, and Vue.
For some time, I was not sure – do I want to be a developer or a teacher?
Then, I took a course on software architecture, and I really loved it. We created projects with UI-UX, UML diagrams, database structures, and Java code that I didn't know . It was very difficult, but very interesting. I understood that I like the whole process. I could spend hours on it and lose track of time. I realized that I want to be a developer. And maybe later, I will teach development too."

"RS School is the next level in my education. Here, I work on more complex projects, follow deadlines, write clean code, and understand other people’s code.
Now, I have some landing pages, a Vue project, and some mini-games, including a nonogram game written in pure JavaScript."

"I want to grow and learn from experienced developers. For me, it is important not just to write code but to write good code and complete projects properly.
I am ready for new challenges. I want to learn, work in a team, and become a better developer.
Thank you for your time!"
